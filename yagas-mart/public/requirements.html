2. Executive Purpose & Business Vision

Yaga's Mart (Sendurai) requires an automated daily morning content publishing system to maintain continuous community engagement. Every morning at 06:00 AM IST, the system generates and dispatches inspiring bilingual (English & Tamil தமிழ்) morning quotes, daily recommended yoga asanas, health tips, and visual posters across 4 target channels:

  • WhatsApp Community Groups (Formatted text payload + Poster image)
  • WhatsApp Status Updates (Vertical 9:16 poster card)
  • Instagram Business Page (@yagas_mart_sendurai_official)
  • Facebook Page (Yaga's Mart, Sendurai)

3. Functional Requirements Specification

Module 1: 31-Day Content Calendar & Weekly Themes

Req IDFeature TitleDescriptionPriority
FR-01 Weekly Theme Rotation Rotates 7 weekly themes: Mindfulness Monday, Asana Tuesday, Pranayama Wednesday, Therapeutic Thursday, Flexibility Friday, Wisdom Saturday, Self-Care Sunday. MUST HAVE
FR-02 Calendar Grid View Display 31-day interactive grid listing theme icon, status badge, English quote, Tamil quote preview, and target asana. MUST HAVE

Module 2: Google Gemini AI Content Engine

Req IDFeature TitleDescriptionPriority
FR-04 Dynamic AI Generation Send prompts to Google Gemini API (gemini-1.5-flash) requesting bilingual quotes, asana tips, benefits, and hashtags. MUST HAVE
FR-06 Intelligent Fallback Seamlessly fall back to built-in wellness database if Gemini API key or network is offline. MUST HAVE

Module 3: Visual Poster Studio & Local Folder Saver

Req IDFeature TitleDescriptionPriority
FR-08 Multi-Aspect Canvas Support live preview for 1:1 Feed (1080x1080) & 9:16 WhatsApp Status (1080x1920) aspect ratios. MUST HAVE
FR-11 Local Folder Auto-Save Export rendered PNG posters automatically to configured local directory path (C:\YagasMartPosters\). MUST HAVE
FR-12 1-Click WhatsApp Copy Copy formatted WhatsApp text payload with emojis and contact details to clipboard. MUST HAVE

4. Non-Functional Requirements

  • NFR-01 Performance: Total execution cycle (AI call + poster rendering + local file save + dispatch) completes within 15 seconds.
  • NFR-02 Reliability: 99.9% uptime with offline zero-downtime fallback mechanism.
  • NFR-03 Security: API keys and access tokens masked with password inputs.
