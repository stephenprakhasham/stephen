3. Class & Component Diagram Architecture

classDiagram
    class App {
        +Array schedule
        +Object selectedDay
        +String activeTab
        +Array logs
        +Object channelConfig
        +handleUpdateItem()
        +handleTriggerNow()
        +handleApplyGeneratedContent()
    }

    class GeminiService {
        +String apiKey
        +generateYogaPost(apiKey, dayNumber, theme, category, language)
        +fallbackDatabase()
    }

    class PostCardPreview {
        +String aspectRatio ('feed'|'status')
        +String themeStyle
        +String fullWhatsAppText
        +handleCopyPayload()
        +renderCanvas()
    }

    class CalendarGrid {
        +Array schedule
        +onSelectDay()
        +onRegenerateDay()
        +onPublishNow()
    }

    class MultiChannelConfig {
        +Object config
        +handleSubmit()
    }

    class CronSimulatorLogs {
        +Array logs
        +onClearLogs()
        +onRunManualTrigger()
    }

    App --> CalendarGrid : passes schedule & triggers
    App --> PostCardPreview : passes selectedDay & handlers
    App --> GeminiService : calls API service
    App --> MultiChannelConfig : passes config state
    App --> CronSimulatorLogs : passes live logs stream

4. Codebase Structure & Component Responsibilities

File PathComponent RoleCore Functions
src/App.jsx Main State Orchestrator Manages 31-day schedule array, active navigation tabs, execution logs, and channel settings.
src/data/yogaSchedule.js 31-Day Content Database Contains 31 days mapped across 7 weekly themes (Mindfulness Monday to Self-Care Sunday) with bilingual quotes.
src/services/geminiService.js Gemini AI Integration Calls gemini-1.5-flash API with structured JSON output prompts; features offline fallback database.
src/components/Header.jsx Navigation & KPI Banner Displays studio branding, cron status badge ("Daily 06:00 AM Cron Active"), stats badges, and tab triggers.
src/components/CalendarGrid.jsx Content Calendar Grid Displays 31 daily cards with status badges, theme icons, quote previews, channel badges, and action triggers.
src/components/PostCardPreview.jsx Poster Studio Canvas Renders 1:1 Feed & 9:16 Status canvas cards, color gradient theme picker, text editor, and 1-click WhatsApp text copy.
